        THE CATALOGUE
        
14 tools, 64 parameters

        
Every tool runs over plain MCP stdio. Open a card to read its parameters — the front
        stays scannable, the detail lives on the back.

      


      

        

          01trademcp_get_quote3 params
          
Latest price quote and key statistics for an Indian stock.

          

            
symbol required
string — NSE symbol or company name, e.g. RELIANCE or tata motors

            
exchange
string — NSE or BSE

            
response_format
markdown or json

          

        


        

          02trademcp_get_fundamentals3 params
          
A full fundamental picture: valuation, profitability, leverage, liquidity, growth and DuPont.

          

            
symbol required
string — NSE symbol or company name, e.g. HDFCBANK

            
include_india_metrics
boolean — add India-specific ratios from Screener.in

            
response_format
markdown or json

        HOW IT WORKS
        
Five steps, then it caches

      


      
    
        
  1. 
          1
          
          
    Resolve
    
          
    RELIANCE, tata motors, NSE:TCS, RELIANCE.NS,
          INE002A01018 and nifty all resolve to the same instrument.
    
        
    2. 
        
  2. 
          2
          
          
    Fetch
    
          
    Prices from Yahoo's chart endpoint, statements from its timeseries endpoint, symbol
          identity from NSE's static CSV listings.
    
        
    3. 
        
  3. 
          3
          
          
    Compute
    
          
    Each ratio is derived from raw statement lines, so valuation, profitability and
          leverage reconcile with each other and with DuPont.
    
        
    4. 
        
  4. 
          4
          
          
    Score
    
          
    Indicators become signals, signals become a composite score from Strong Buy to
          Strong Sell, explained in plain language.
    
        
    5. 
        
  5. 
          5
          
          
    Cache
    
          
    Responses are cached on disk with per-type TTLs, so repeated screens stay off the
          free endpoints and stay fast.

        SOURCES
        
Three sources. All free. All keyless.

        
If a source changes its markup, that one section degrades. The rest keeps working.

      


      

        

          YF
          
Yahoo Finance

          
Chart, quote and fundamentals-timeseries. Public JSON endpoints; the quote
          endpoint needs a free cookie and crumb handshake, which the server does itself.

          
    
            
  • OHLCV candles, 52-week range
    • 
            
  • Price, market cap, multiples, dividend yield
    • 
            
  • Annual, quarterly and trailing statement lines
    • 
          

        

        

          NSE
          
NSE static archives

          
Symbol universe, company names, ISIN, industry and index membership, from static
          CSV listings that need no session.

          
    
            
  • NIFTY 50 / 100 / 500 listings
    • 
            
  • Full listed-company equity universe
    • 
            
  • Not behind the bot protection on the live JSON API
    • 
          

        

        

          SC
          
Screener.in

          
India-specific ratios and ownership, parsed defensively and treated as optional.

          
    
            
  • ROCE and book value, on Screener's own definition
    • 
            
  • Promoter, FII, DII and public holding
    • 
            
  • Debtor days, inventory days, cash conversion cycle
    • 
          

        

      

      
TradeMCP reports ROCE as EBIT ÷ invested capital. Screener.in reports its
      own ROCE on a different capital base. Both are shown; they are never merged.

    


    
    

      

        INSTALL
        
One command, then restart your client

        
One command installs the server and hands it to your client. No key, no signup, no
        dashboard.

      


      

        

          

            npx
            
              
              
            
          


npx -y @aswathas/trademcp

          
That is the whole install. The package carries the Python
          server and builds its own environment on first run, so all you need is Node 18+ and
          Python 3.11+. No clone, no venv, no pip. The first run spends about half a minute
          building that environment; every run after that is about a second.


          

            Global install
            
          


npm i -g @aswathas/trademcp

          
If your MCP client has a short start-up timeout, install the
          package once like this and point the client at the trademcp command
          instead of npx. The environment is built at install time, so the server
          starts in about a second.


          

            claude_desktop_config.json
            
          


{
  "mcpServers": {
    "trademcp": {
      "command": "npx",
      "args": ["-y", "@aswathas/trademcp"]
    }
  }
}

          
For Claude Desktop, Cursor, Windsurf and VS Code. In Claude Code
          it is a single line: claude mcp add trademcp -- npx -y @aswathas/trademcp.


          

            Manual setup
            
          


{
  "mcpServers": {
    "trademcp": {
      "command": "python",
      "args": ["-m", "trademcp"]
    }
  }
}

          
If you installed from source and want to point at your own
          interpreter, use this instead: git clone, python -m venv .venv,
          pip install -e ., then python -m trademcp.
          python must be the interpreter that has TradeMCP installed —
          scripts/install.ps1 prints the exact path to paste. Installed globally
          instead? Use "command": "trademcp" with no args.
